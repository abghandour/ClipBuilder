Welcome to Clip Builder

This installer will:

  • Install Clip Builder into your Applications folder
  • Open a Terminal window after installation that installs everything else the app needs:
    • ffmpeg — the video engine
    • yt-dlp — for video downloads
  • Let you choose which AI providers to install (Claude Code, Gemini CLI, Codex CLI, Qwen Code, Kimi Code CLI) — each is optional and can also be added later by re-running setup
  • Guide you through signing in to each installed provider (now or later — your choice)
  • Help you create your first brand profile

Everything installs into your user folder — no Homebrew or Xcode tools needed. An internet connection is required.
